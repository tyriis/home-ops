# Media - Seerr

Seerr manages media requests and discovery for the Plex stack.

- App: `kubernetes/main/apps/media/seerr`
- URL: `https://seerr.techtales.io`
- Image: `ghcr.io/seerr-team/seerr`

The database runs in Postgres (`cloudnative-pg`), not in the pod.

Related pages: [Storage](storage.md).
